# LEAF

Life Event & Agenda Framework — Windows 바탕화면 일정관리 프로그램입니다.

캘린더, 날짜별 메모, 반복 일정, 체크리스트, 알람, 사진 액자와 선택형 모듈(오늘 일정, 오늘 브리핑, 주간 목표)을 제공합니다.

## 다운로드

이 저장소(LEAF-Releases)의 **Releases**에서 테스트 릴리스를 선택하고,
Assets의 `LEAF-v0.1.0-alpha-win64.zip`을 내려받으세요.
GitHub가 자동 생성하는 Source code ZIP은 실행 프로그램이 아닙니다.

Windows 10/11 x64용입니다. Python을 별도로 설치하지 않아도 되도록 런타임을 포함합니다.
전체 압축을 풀고 `LEAF/LEAF.exe`를 실행하세요. 자세한 내용은 [INSTALL.md](INSTALL.md)를 참고하세요.

이 저장소에는 실행 패키지와 사용자 문서만 게시합니다. 개발 소스는 비공개 LEAF-Source에서 관리합니다.

## 테스트 및 오류 제보

초기 알파 버전입니다. [현재 릴리스 안내](RELEASE_NOTES.md)를 확인하세요.
Issues에 앱 버전, Windows 버전, 재현 절차와 기대 동작을 남겨 주세요.
일정·메모·사진·로그에는 개인 정보가 포함될 수 있으니 원본 데이터 파일을 공개 첨부하지 마세요.

자동 업데이트 기능은 아직 없습니다. 새 ZIP을 별도 폴더에 풀어 실행하면 같은 Windows 계정의 기존 데이터를 사용합니다.
